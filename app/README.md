# 可运行程序

本地软件统一放在这个文件夹中。

- 双击本文件夹内的 `FanScope.exe`。
- 也可以双击项目根目录的 **打开软件.cmd**。
- 构建脚本会将最新版 EXE 复制到这里，所需依赖和许可证已内嵌。

GitHub 通过 [Releases](https://github.com/JahsehXL/FanScope/releases/latest) 分发编译好的 Windows 程序。下载单文件 `FanScope.exe` 后，可将其放入本文件夹，再运行根目录的启动入口。

源代码位于 [src](../src)，打包脚本位于 [scripts/build_exe.py](../scripts/build_exe.py)。
