# 隐私与网络说明

## 采集结果本地处理

粉丝记录、HAR 解析结果和 Excel 在本机处理、保存。当前软件未实现将这些数据自动上传给开发者的接口，也未集成遥测和自动更新服务。

默认目录为 `%LOCALAPPDATA%\FanScope`，其中 `data/` 保存记录和表格，`browser-profile/` 保存专用 Edge 的登录状态。可通过 `FANSCOPE_HOME` 指定其他位置。

## 联网范围

- HAR 导入、去重、排序和 Excel 导出可离线运行。
- 实时采集使用真实 Edge 访问抖音及页面资源，网页会发送正常请求和登录凭据。
- 本机数据若放入云盘同步目录，或由用户主动分享，其传播范围由对应操作决定。

## 使用边界

独立浏览器配置用于分开采集与日常浏览的登录数据。模拟滚动和受限暂停机制仍可能遇到平台验证或限制，请遵守适用法律及[平台规则](https://www.douyin.com/draft/douyin_agreement/douyin_agreement_user.html?id=6773906068725565448)。

HAR、登录状态、表格和粉丝信息请妥善保管。反馈问题时提供脱敏信息。
